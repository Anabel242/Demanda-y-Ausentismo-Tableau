# Demanda-y-Ausentismo-Tableau
Turnos otorgados y atendidos en el Centro Médico del Norte entre enero y agosto de 2025, analiza el comportamiento de la demanda, la asistencia y el ausentismo en el ámbito ambulatorio.  El análisis se desarrolló para Gerencia Operativa, con el propósito de optimizar la planificación de agendas, recursos y estrategias de retención de pacientes.

El dataset incluye información proveniente de los sistemas internos de turnos y registros asistenciales, estructurada a nivel de turno individual.

Entre las variables principales se incluyen:
♦Fecha del turno y fecha de otorgamiento
♦Sede
♦Especialidad médica
♦Servicio de la especialidad
♦Estado del turno (Presente/Ausente)
♦Origen de solicitud (online, presencial, telefónica, WhatsApp, etc.)
♦Obra social o prepaga
♦Género del paciente
♦Tipo de turno (Programado/Espontáneo)
